# Travelling Website

This is a simple and attractive Travelling Website created using HTML, CSS, and JavaScript.

The website helps users explore different travel destinations and view beautiful places around the world.

**Technologies Used:**
- HTML
- CSS
- JavaScript

**Features:**
- Attractive website design
- Beautiful destination images
- Easy navigation
- User-friendly interface

**Project Objective:**
To create a simple website that helps users explore different travel destinations.
